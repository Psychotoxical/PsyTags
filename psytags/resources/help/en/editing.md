# Changing tags by hand

## The file list

- **Open folder** (Ctrl+D) replaces the list, **Add folder** (Ctrl+H) adds to it, **Refresh** (F5) reads it again.
- The search field (Ctrl+F) filters across all columns.
- A right click on the column headers shows and hides columns. **Customize columns...** in the same menu sets them up in detail.
- **Play** (F4) starts the selected files.
- **Del** only takes files off the list. They stay on your disk.

## The Tag Panel

On the right are the fields of the selected files. If several files are selected and their values differ, the field says so, and a change applies to all selected files. **Save tag** (Ctrl+S) writes it. Ctrl+Q hides and shows the panel, **Customize Tag Panel...** in the ≡ menu decides which fields it has.

**Extended Tags** (Alt+T) shows all fields of a file, even rare ones.

## Copy and undo

Ctrl+C and Ctrl+V copy the tag of a file or selected text. **Remove tag** (Ctrl+R) deletes the tag of the selected files.

**Undo** (Ctrl+Z) and **Redo** (Ctrl+Y) work for tags and renames while the program is running.
