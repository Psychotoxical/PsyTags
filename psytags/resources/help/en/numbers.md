# Numbers

**Write numbers** (Ctrl+K) writes track and disc numbers of the selected albums. This also happens in the automatic run.

The order inside an album follows disc and track.

Under **Options → Numbers** you set the format:

| Setting | Example |
|---|---|
| Track with leading zero | 03 instead of 3 |
| Track with total | 03/12 instead of 03 |
| Write disc number | Write the disc at all |
| Disc with leading zero | 01 instead of 1 |
| Disc with total | 01/02 instead of 01 |
