# Cover

## Where covers come from

The **Cover Art Archive**, the picture archive of MusicBrainz, comes with the program. It only finds covers for albums with a MusicBrainz ID. Add more sources with [cover plugins](help:plugins).

Under **Options → Automatic → Cover** you switch sources on and off and drag them into the order you want. From top to bottom, the first source that delivers a cover wins.

## How to get covers

- In the automatic run this is a step of its own.
- **Cover** in the bar at the top fetches the covers of the selected albums.
- A right click on the cover in the Tag Panel offers **Load cover from …** for each source. If no match is certain, you pick from the list.
- The same entries are in the right-click menu of the file list under **Fetch cover**, plus **All sources in order**.

In the same menu you can add (Ctrl+Alt+A), replace, remove and view covers.

## Minimum size

Under **Options → Automatic → Cover → Minimum size** you set how large a cover must at least be. Smaller ones are not taken. 0 takes everything.

The automatic run only takes a certain match, so a wrong cover does not end up in your files. Whatever failed can be retried in the [summary](help:summary).
