# Options

**Options** (Ctrl+O) has four pages, chosen with the cards at the top. The **setup assistant** in the ≡ menu leads through the most important things step by step and can be opened again at any time.

**Automatic** shows the steps of **All albums automatically** in their order. Every step except MusicBrainz has a switch; the run leaves out what is switched off. Numbers and cover also apply after a manual search.

| Step | What you set |
|---|---|
| 1 Moods | Whether the run analyzes the moods first, how many a song gets |
| 2 MusicBrainz | Whether comments are deleted on import (default: off), year only or the full release date, whether digital releases are preferred |
| 3 Numbers | Whether track and disc numbers are written, their format |
| 4 Cover | Whether covers are fetched, sources and their order, whether existing covers are replaced, minimum size |
| 5 Genres | Last.fm on or off |

| Page | What you set |
|---|---|
| Accounts and sources | Discogs token, Last.fm API key, [cover plugins](help:plugins) |
| Files | ID3 version for MP3, additional ID3v1, read subfolders, save automatically when the selection changes, leave the modification date of files alone |
| Program | Language and theme, they apply at once |

With **Replace existing covers** off, albums that already have a cover keep it. A cover you fetch by hand always replaces the old one.

Behind the Last.fm and Discogs fields, a green check mark shows that the server accepts the key. A red cross means: not accepted, or the server cannot be reached right now.

**Open settings folder** in the ≡ menu shows where PsyTags keeps its settings.
