# Rename

In step 6, **Selection** takes the selected files and **All** the whole list.

**Rename** (Alt+1) names the selected files after a scheme you click together from chips. There is nothing to type and no format language.

## Building the scheme

- A click on a chip adds it.
- In the scheme, a click removes a chip and dragging changes the order.
- **New folder** starts a subfolder.
- **Default** brings back the scheme that comes with the program.

The preview shows on one of your files what the result will be. If a value is missing, such as the year, the brackets and separators around it disappear too.

The default is `Album artist - (Year) - Album / Track-Disc - Artist - Title`.

## Old folders

With **Move old folders and leftovers such as images to the recycle bin** on, PsyTags puts the new albums next to the old folders and moves the old ones to the recycle bin once no audio file is left in them. Leave this off for your first attempts.

## Good to know

Characters that are not allowed in file names are replaced. If a path gets too long on Windows, the file name is shortened. On Linux and macOS the limit applies to each single name, 255 bytes.

**Undo** (Ctrl+Z) takes back a rename. Anything in the recycle bin can be restored from there.
