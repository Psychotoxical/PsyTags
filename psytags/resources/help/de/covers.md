# Cover

## Woher die Cover kommen

Mitgeliefert ist das **Cover Art Archive**, das Bilder-Archiv zu MusicBrainz. Es findet Cover nur für Alben mit einer MusicBrainz-ID. Weitere Quellen fügen Sie mit [Cover-Plugins](help:plugins) hinzu.

Unter **Optionen → Automatik → Cover** schalten Sie Quellen ein und aus und ziehen sie in die gewünschte Reihenfolge. Von oben nach unten gilt: Die erste Quelle, die ein Cover liefert, gewinnt.

## So holen Sie Cover

- Beim automatischen Lauf ist das ein eigener Schritt.
- **Cover** in der Leiste oben holt die Cover der markierten Alben.
- Ein Rechtsklick auf das Cover im Tag-Panel bietet **Cover von … laden** für jede Quelle an. Ist kein Treffer sicher, wählen Sie aus der Liste.
- Dieselben Einträge stehen im Rechtsklick-Menü der Dateiliste unter **Cover holen**, dazu **Alle Quellen der Reihe nach**.

Im selben Menü können Sie Cover hinzufügen (Strg+Alt+A), ersetzen, entfernen und ansehen.

## Mindestgröße

Unter **Optionen → Automatik → Cover → Mindestgröße** legen Sie fest, wie groß ein Cover mindestens sein muss. Kleinere werden nicht übernommen. 0 nimmt alles.

Beim automatischen Lauf wird nur ein sicherer Treffer genommen, damit kein falsches Cover in Ihren Dateien landet. Was nicht geklappt hat, holen Sie in der [Übersicht](help:summary) nach.
