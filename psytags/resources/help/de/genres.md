# Genres

Die Genres kommen von Last.fm. PsyTags fragt zuerst die Tags des Albums, findet es dort nichts, die des Künstlers, und übernimmt nur Einträge, die wirklich Genres sind.

Dafür brauchen Sie einen eigenen, kostenlosen API-Key von [last.fm/api/account/create](https://www.last.fm/api/account/create). Tragen Sie ihn unter **Optionen → Genres** ein. Ein grüner Haken zeigt, dass er funktioniert.

**Genres von Last.fm holen** (Strg+Shift+L) schreibt die Genres der markierten Dateien. Beim automatischen Lauf ist das der letzte Schritt. Findet Last.fm nichts, bleibt das Feld GENRE, wie es war.

Was nicht geklappt hat, holen Sie in der [Übersicht](help:summary) nach.
