# Optionen

**Optionen** (Strg+O) hat vier Seiten, oben wählen Sie sie als Karten. Der **Einrichtungs-Assistent** aus dem Menü ≡ führt Schritt für Schritt durch das Wichtigste und lässt sich jederzeit wieder öffnen.

**Automatik** zeigt die Schritte von **Alle Alben automatisch** in ihrer Reihenfolge. Jeder Schritt außer MusicBrainz hat einen Schalter; was ausgeschaltet ist, lässt der Lauf weg. Nummern und Cover gelten auch nach einer manuellen Suche.

| Schritt | Was Sie einstellen |
|---|---|
| 1 Moods | Ob der Lauf zuerst die Moods analysiert, wie viele ein Song bekommt |
| 2 MusicBrainz | Ob Kommentare beim Import gelöscht werden (Standard: aus), nur das Jahr oder das volle Erscheinungsdatum, ob digitale Ausgaben bevorzugt werden |
| 3 Nummern | Ob Track- und Discnummern geschrieben werden, ihr Format |
| 4 Cover | Ob Cover geholt werden, Quellen und ihre Reihenfolge, ob vorhandene Cover ersetzt werden, Mindestgröße |
| 5 Genres | Last.fm ein oder aus |

| Seite | Was Sie einstellen |
|---|---|
| Konten und Quellen | Discogs-Token, Last.fm-API-Key, [Cover-Plugins](help:plugins) |
| Dateien | ID3-Version für MP3, zusätzliches ID3v1, Unterordner einlesen, automatisch speichern beim Wechsel der Auswahl, Änderungsdatum der Dateien nicht anfassen |
| Programm | Sprache und Design, sie gelten sofort |

Ist **Vorhandene Cover ersetzen** aus, behalten Alben, die schon ein Cover haben, ihr Cover. Ein Cover, das Sie von Hand holen, ersetzt das alte immer.

Hinter dem Last.fm- und dem Discogs-Feld zeigt ein grüner Haken, dass der Server den Schlüssel annimmt. Ein rotes Kreuz heißt: nicht angenommen, oder der Server ist gerade nicht erreichbar.

**Einstellungsordner öffnen** im Menü ≡ zeigt, wo PsyTags seine Einstellungen speichert.
